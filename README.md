# Wallpapers

A collection of wallpapers created with [Midjourney](https://www.midjourney.com/) and [ElevenLabs](https://elevenlabs.io/).

## Formats

| Folder | Aspect Ratio | Use Case |
|--------|-------------|----------|
| `16x9` | 16:9 | Standard monitors |
| `16x18` | 16:18 | Dual monitor (stacked) |
| `32x9` | 32:9 | Ultra-wide / dual monitor (side by side) |

## Usage

Feel free to use these wallpapers for personal or commercial purposes. Attribution is appreciated.
